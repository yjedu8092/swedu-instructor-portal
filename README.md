# SW교육센터 강사 포털 (프로토타입)

교육기관용 소개 페이지 + 강사 포털 데모입니다. 빌드 도구 없이 정적 파일만으로 동작합니다.
화면의 모든 데이터(강사·일정·대여·청구·공지·채용)는 **예시 데이터**입니다.

## 실행
```bash
python3 -m http.server 8000
```
http://localhost:8000 접속 → "강사 로그인"
- 강사: 휴대폰 번호(010-XXXX-XXXX 형식) + 비밀번호 4자 이상 (초기 비밀번호 데모값 `1234`)
- 운영팀: 로그인 화면에서 "운영팀(관리자)" 선택

## 기관 정보 바꾸기
`app.js` 맨 위 `CONFIG` 한 곳만 수정하면 화면 전체에 반영됩니다.
센터 이름, 주소, 전화, 지도 검색어, 공식 포털, 차시 단가(주강사/보조강사), 교구운반비 정책 금액, 입실 허용 반경.
`operator`(운영기관·사업자 정보)는 비워두면 화면에 표시되지 않습니다.
교육장 목록과 좌표는 `SITES`, 관리자 목록은 `MANAGERS`, 대여 자산은 `ASSETS`에 있습니다.

## 강사 메뉴 (사용자 가이드 기준)
| 메뉴 | 기능 |
|---|---|
| 입퇴실 | 교육장·역할(주강사/보조강사) 선택 → 입실 → 근무중 경과 시간 → 퇴실 → 수업차시 승인신청(적용 단가 표시). GPS 반경 확인, 반경 밖/위치 실패 시 사유 입력 후 예외 기록, 기기 정보 기록, 퇴실 미처리 경고와 사후 처리 |
| 근무기록 | 기간·상태·교육장 필터, 총 일수·차시·대기 합계, 카드 펼쳐 상세(위치·기기·시간차·지도), 엑셀 다운로드 / 표 복사, 수정 요청 |
| 스케줄 | 월간·주간 달력, "N차시" 블록(실시 완료/예정 색 구분), 이번 달 총 차시, 날짜별 상세 |
| 대여신청 | 관리자·자산·수량·희망 불출 시간·반납 예정일·활용 현장·대여자·반납자·비고. 이틀 전 17시 마감 검증, 재고 검증. 상태: 승인대기 → 대여예정 → 대여중 → 연체 → 반납확인중 → 반납완료. 신청 취소·반납 신청·재신청 |
| 비용청구 | 수당/실비, 여비(영수증 첨부)·교구운반비(본인 대여건 필수, 정책 금액). 청구이력, 거절 사유, 승인대기 건 수정·취소, 거절 건 재신청 |
| 관리자에게 문의 | 관리자·카테고리(대여/정산/증명서/일반)·제목·내용, 문의이력 스레드, 추가 답글, 종료된 문의는 답글 불가 |
| 내 정보 | 비밀번호 변경(8자 이상, 영문+숫자), 초기 비밀번호 경고, 알림 설정 |

공통: 모든 메뉴의 **도움말** 버튼, 종 모양 **알림**, 첫 로그인 시 **수업 알림 받기** 안내(나중에 → 24시간 후 재안내).

## 추가 기능
- 정산 명세: 승인 차시 × 단가 + 승인 수당 − 원천징수 3.3% + 승인 실비
- 전자계약(손글씨 서명), 서류 작성(전자결재)
- 운영팀: 승인함(차시·청구·대여·반납·서류·문의·지원서, 예외 없는 차시 일괄 승인), 문의 답변·종료, 채용·공지 관리
- 소개 페이지: 채용공고 필터·검색·온라인 지원·알림 신청, 공지, FAQ, 다크모드, 모바일 대응

## 게시
`./build.sh` → `dist/`가 claude.ai 아티팩트 게시용입니다. 아티팩트 화면에서는 인쇄·파일 다운로드·GPS가 막혀 있어
"표 복사", "명세 복사", "사유 입력 후 예외 기록"으로 대신 동작합니다. 직접 호스팅하면 모두 정상 동작합니다.

## 실서비스 전환 시 필요한 것
데이터는 브라우저 localStorage에만 저장됩니다. 실제 운영에는 서버 API·DB·인증(휴대폰 번호 로그인, 비밀번호 해시),
푸시 알림(Web Push), 파일 저장소(영수증)가 필요합니다.
